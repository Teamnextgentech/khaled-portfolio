# Khaled Ellahib — Product Portfolio

Public portfolio featuring **ADAPT Fitness**, an AI-assisted fitness platform combining personalized training, movement analysis, recovery/readiness, progress tracking, and AURA coaching.

## What this repo contains

- `index.html` — portfolio case study
- `styles.css` — responsive dark-mode design system
- `script.js` — scroll/reveal interactions
- `assets/` — lightweight public ADAPT/AURA portfolio visuals

## ADAPT stack highlighted

React 18 · Vite · Supabase · Postgres · Auth · RLS · Node serverless APIs · MediaPipe · Stripe · Vercel · PWA

## Public disclosure note

This repository intentionally excludes the private ADAPT application source code and confidential IP material. Future/R&D concepts are labeled separately from implemented capabilities.

## Deployment

This is a static site and can be deployed directly with Vercel, Netlify, or GitHub Pages with no build command required.
